# Manuscript Checklist

> A section-by-section checklist built from general research-writing and reproducibility principles
> (see [`../principles/research-writing-principles.md`](../principles/research-writing-principles.md)).
> Each item is marked **[auto]** (machine-checkable by the toolkit's validator) or **[human]**
> (requires author/domain-expert review).

## A. Research framing
- [ ] **[human]** Research question stated explicitly and is Feasible/Novel/Significant/Specific.
- [ ] **[human]** Hypothesis present only if the design is quantitative/confirmatory.
- [ ] **[human]** Research Gap grounded in cited literature (not "nobody built this").
- [ ] **[auto]** Question, hypothesis, objectives, contributions all present in project config.
- [ ] **[human]** Contributions are genuinely new (Novelty / Empirical Evidence / Practical Value).

## B. Title, abstract, keywords
- [ ] **[human]** Title is an honest one-line summary (no overclaim).
- [ ] **[human]** Abstract reflects actual findings; is not a shrunken introduction.
- [ ] **[auto]** Keywords present; consistent with title and abstract.

## C. Introduction & literature review
- [ ] **[human]** Introduction follows the funnel and ends with RQs + Contributions.
- [ ] **[human]** Literature review is synthesis grouped by theme/method (not a list).
- [ ] **[auto]** A literature matrix exists for the cited works.
- [ ] **[human]** No claim of exhaustive coverage without a documented search strategy.

## D. Methodology
- [ ] **[human]** Methodology describes *how it was verified*, not just *what was built*.
- [ ] **[human]** Assumptions, preprocessing, data source/size/split documented.
- [ ] **[human]** Sample-size justification appropriate to the method.
- [ ] **[human]** Data-leakage avoided (split before scaling; entity-level split).
- [ ] **[human]** Equations dimensionally consistent; notation table present (if mathematical).
- [ ] **[human]** Reproduced/adapted equations distinguished from new derivations.

## E. Implementation & experiments
- [ ] **[human]** Reproducibility info complete (hardware, versions, seeds, runs).
- [ ] **[human]** Baselines include one classic and one recent/SOTA; same data/split/metric.
- [ ] **[auto]** Results come from saved evidence files (not hand-typed numbers).
- [ ] **[human]** Manuscript description matches the code/experiment that actually ran.
- [ ] **[auto]** Experiments that did not run are marked results-unavailable.

## F. Results, discussion, figures
- [ ] **[human]** Results are factual only; interpretation lives in Discussion.
- [ ] **[human]** No causal claim unsupported by the study design.
- [ ] **[human]** Metric choice justified; accuracy not reported alone on imbalanced data.
- [ ] **[human]** Negative/unexpected results reported honestly.
- [ ] **[human]** Every figure passes the stranger test; axes labelled with units; grayscale-safe.
- [ ] **[auto]** Every figure has a provenance note (data source or "conceptual").
- [ ] **[auto]** No quantitative chart generated by an image model.

## G. Limitations, conclusion
- [ ] **[human]** Honest Limitations section present; limits are relevant and paired with impact.
- [ ] **[human]** Future Work traceable to a stated limitation.
- [ ] **[auto]** Conclusion contains no new result/citation; answers the RQs without overclaiming.

## H. References & citations
- [ ] **[human]** Every citation personally verified against the source.
- [ ] **[auto]** Citation style consistent; primary sources with DOIs preferred.
- [ ] **[auto]** Every in-text citation resolves to a bibliography entry and vice versa.
- [ ] **[auto]** Unverifiable references explicitly flagged.
- [ ] **[auto]** No invented authors/titles/DOIs/URLs/quotes.

## I. Integrity & ethics
- [ ] **[human]** No fabrication/falsification; data cleaning explained.
- [ ] **[human]** No plagiarism/self-plagiarism/duplicate publication/salami slicing.
- [ ] **[human]** Human-subjects: consent, anonymization, IRB/ethics approval documented.
- [ ] **[human]** Funding and conflicts of interest declared; AI-tool use disclosed.
- [ ] **[auto]** Researcher's permitted source set respected (no out-of-scope sources).

## J. Clarity & language
- [ ] **[human]** One idea per paragraph; consistent terminology; wordiness trimmed.
- [ ] **[human]** Voice consistent and venue-appropriate.

## K. Publication readiness (signals only — never a guarantee)
- [ ] **[human]** Target venue scope fit; venue screened against predatory checklist.
- [ ] **[human]** No claim that the manuscript is accepted or guaranteed to pass review.

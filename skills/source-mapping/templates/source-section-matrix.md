## 3. Claims-traceability table

One row per substantive claim. The supporting source id(s) **must** come from the claim's section's
assigned set. `kind` records whether the statement is a verified fact, interpretation, assumption, or
proposed/future work. `status` is one of `supported`, `gap`, or `out-of-scope-needed`.

| Claim (short) | Section | Supporting source id(s) | kind | status |
|---------------|---------|-------------------------|------|--------|
| "Rule-based detectors miss novel patterns" | literature-review | `src1`, `src3` | verified-fact | supported |
| "Method M reduces latency by ~40%" | results | (none yet) | proposed/future | gap |
| "Prior work X used the same dataset" | methodology | `src4` (assigned to literature-review only) | verified-fact | out-of-scope-needed |

## 4. Gaps report

> Always present, even when empty. These are **decisions for the researcher**, not items to be
> auto-resolved by inventing or borrowing sources.

### 4.1 Evidence gaps (status = `gap`)
- [ ] <section> — "<claim>" has no assigned source that supports it. Options: add/assign a source,
      soften the claim, or mark it explicitly as proposed/future work.

### 4.2 Out-of-scope-needed (status = `out-of-scope-needed`)
- [ ] <section> — "<claim>" could be supported by `<sourceId>`, but that source is not assigned to
      this section. Researcher decision required: reassign in `sectionSources`, or support the claim
      another way.

### 4.3 Dangling references (assigned id not found in `sources[]`)
- [ ] <section> — assigned source id `<id>` does not exist in project `sources[]`. Fix the id or add
      the source to the inventory.

### 4.4 Provenance caveats (unverified / incomplete metadata used)
- [ ] <section> — uses `<sourceId>` with `verificationStatus: unverified` / `metadataComplete: false`.
      Citation is provisional until verified by `reference-auditor`.
